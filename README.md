# 👶 우리들의 육아 이야기

임신부터 돌까지, 부모가 되는 여정을 **이상형 월드컵 방식의 선택**으로 경험하는 인터랙티브 스토리 게임입니다.
중요한 순간마다 두 카드 중 마음이 가는 쪽을 고르고(3~4개 선택지는 4강 → 결승 토너먼트),
**다른 부모들은 어떤 선택을 했는지 통계로** 확인할 수 있어요.

## 🎯 누구를 위한 게임인가요?

- 출산을 앞두고 "우리는 어떻게 하지?"를 미리 그려보고 싶은 **예비 부부**
- 매일 크고 작은 육아 선택 앞에서 고민하는 **초보 부모**
- 부부가 함께 플레이하며 **서로의 육아관을 미리 맞춰보고 싶은** 커플

정답을 알려주는 게임이 아닙니다. "이런 순간이 온다"를 미리 겪어보고,
부부가 대화를 시작하게 만드는 것이 목표입니다.

## 🕹️ 플레이 방법

정적 웹앱이라 별도 설치·빌드가 필요 없습니다.

```bash
# 저장소를 받은 뒤 index.html을 브라우저로 열거나
open index.html

# 간단한 로컬 서버로 열기
python3 -m http.server 8000   # → http://localhost:8000
```

GitHub Pages(Settings → Pages → 브랜치 배포)로 바로 배포할 수 있습니다.

## ✨ 주요 기능

- **이상형 월드컵 선택**: 모든 선택은 두 카드의 VS 대결. 선택지가 3~4개인 문항은 4강 → 결승 토너먼트로 진행되어 최종 우승 선택이 기록됨
- **선택 카드 이미지**: 기본은 이모지 일러스트 카드. `js/data.js`의 옵션에 `img: "images/파일.jpg"`를 추가하면 실제 사진/일러스트로 교체됨
- **아기 설정**: 아들/딸/모름(출산 씬에서 랜덤 공개!), 한 명/쌍둥이 — 스토리 텍스트에 반영
- **태명 짓기**: 입력한 태명이 전체 이야기에 등장 (받침에 따라 이/가·은/는 조사 자동 처리)
- **선택 통계**: 최종 선택 직후 "다른 부모들의 선택" 비율을 바 차트로 표시
- **정보 카드**: 각 선택 뒤에 관련 제도·의학 상식 한 줄 팁 제공
- **육아 성향 분석 엔딩**: 선택에 붙은 태그(계획/실속/교감/팀워크)를 집계해 성향 유형 카드 제공, 전체 선택 리뷰 + 다수 선택과의 일치율 표시
- **저장**: localStorage 자동 저장, 이어하기 / 챕터별 재플레이 지원
- **다크 모드 / 모바일 대응 / 모션 최소화 설정 존중**

## 📊 통계 데이터에 대해

현재 버전은 백엔드 없는 MVP입니다. 통계는 `js/data.js`의 `STATS_SEED`
(시뮬레이션 시드값) + 내 기기의 선택 기록(localStorage)을 합산해 보여줍니다.

실제 서비스로 전환할 때는 `js/app.js`의 `Stats` 모듈(`record` / `get`)만
서버 API 호출로 교체하면 됩니다. (예: Supabase/Firebase에 `qid`, `optionId`
카운터 테이블 하나면 충분)

## 🗂️ 코드 구조

```
index.html      # 진입점 (SPA 셸)
css/style.css   # 테마(라이트/다크), 화면별 스타일
js/data.js      # 스토리 데이터(챕터·씬·선택지·태그), 통계 시드
js/app.js       # 게임 엔진: 화면 렌더링, 상태/저장, 통계, 성향 분석
```

씬은 `story`(내레이션) / `choice`(선택+통계) / `input`(태명 입력) 세 타입의
데이터로만 정의되므로, `js/data.js`에 씬을 추가하는 것만으로 이야기를 확장할 수 있습니다.
